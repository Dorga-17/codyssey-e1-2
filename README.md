# E1-2 | 철학·심리학·경제학 퀴즈 게임

## 1. 프로젝트 개요
Python으로 제작하는 콘솔 기반 4지선다형 퀴즈 게임입니다.

## 2. 퀴즈 주제 및 선정 이유
- 주제: 철학, 심리학, 경제학
- 선정 이유: 추후 작성

## 3. 실행 환경 및 방법
- Python 3.12 이상 호환을 목표로 개발
- 실행 방법: 프로그램 구현 후 작성

## 4. 주요 기능
- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 보기 및 사용자 추가 문제 삭제
- 최고 점수 및 전체 플레이 기록 확인
- JSON 데이터 저장 및 불러오기
- 랜덤 출제, 문제 수 선택, 힌트 및 감점

※ 위 기능은 구현 목표이며, 현재 개발 준비 단계입니다.

## 5. 프로젝트 파일 구조
프로그램 구현에 따라 업데이트할 예정입니다.

## 6. 데이터 파일 설명
- `state.json`: 퀴즈, 최고 점수, 플레이 기록을 저장하는 파일
- UTF-8 인코딩 사용 예정

## 7. 검증 및 실행 결과
기능 구현과 검증을 완료한 뒤 기록할 예정입니다.
